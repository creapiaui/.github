# CREA Piauí

👷‍♀️👷‍♂️ **Conselho Regional de Engenharia e Agronomia do Piauí (CREA-PI)**

O CREA-PI é a autarquia federal responsável pela fiscalização, orientação e valorização do exercício profissional das áreas de Engenharia, Agronomia e Geociências no estado do Piauí.

---

## 📌 Sobre esta organização

Este espaço no GitHub é utilizado para:

- Hospedar **projetos de software institucionais**
- Manter **códigos-fonte de sistemas internos e públicos**
- Publicar **APIs, integrações e ferramentas**
- Promover **boas práticas de desenvolvimento e transparência**

---

## 🤝 Contribuições

- Contribuições externas podem ser aceitas conforme a política de cada repositório
- Verifique sempre o arquivo `CONTRIBUTING.md`, quando disponível
- Issues podem ser usadas para reportar bugs ou sugestões

---

## 🔐 Segurança e dados

- Nenhum repositório deve conter **dados pessoais sensíveis**
- O tratamento de dados segue a **LGPD (Lei nº 13.709/2018)**
- Vulnerabilidades podem ser reportadas de forma responsável
